# AGENTS.md

> **Project:** Multi-repo workspace for managing cloned repositories under a single umbrella.
> **Core constraint:** Each repo is independently versioned and gitignored — the workspace tracks only orchestration files and agent context.

## Toolchain

| Action | Command | Notes |
|---|---|---|
| Init workspace | Run `prompts/init.md` | Discovers repos, populates this file, audits each repo |
| Add repo | Run `prompts/add-repo.md` with clone URL | Clones, registers, audits in one step |
| Audit repo | Run `prompts/audit.md` from repo root | Generates `docs/agents/` (human reference) and `AGENTS.md` |
| Remove repo | Delete directory, re-run `prompts/init.md` | Cleans up stale entries |
| Migrate to v2 | Run `prompts/migrate-v2.md` from workspace root | One-time migration from original template format |

## Judgment Boundaries

**NEVER**
- Commit secrets, tokens, connection strings, or internal URLs to any file
- Modify a repo without first reading its `AGENTS.md`
- Guess at repo structure or conventions — read actual files

**ASK**
- Before running destructive operations (force push, reset, branch deletion)
- Before adding cross-repo dependencies
- Before modifying workspace-level files (`AGENTS.md`, `.gitignore`) outside of prompts

**ALWAYS**
- Read the target repo's `AGENTS.md` before making changes in it
- Use environment variable *names* only in documentation — never values
- Return to workspace root before switching to another repo
